A page that embeds Bill Companion

Everything below the line is the embed. The toolbar carries a ⛶ button that only appears when the app is framed.

This host page grants allow="fullscreen". Remove it from the <iframe> and the button falls back to opening the app in a new tab, because the Fullscreen API is refused without it.

Bill Companion is built by Keller Scholl. Bills are parsed in the browser; the embed uploads nothing.
